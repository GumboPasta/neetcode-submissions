# Evaluate Reverse Polish Notation

**Difficulty:** Medium

Evaluate an arithmetic expression given as an array of tokens in Reverse Polish Notation. Valid operators are +, -, *, and /, and division between two integers should truncate toward zero.

## Example 1

Input: tokens = ["2", "1", "+", "3", "*"]
Output: 9
Explanation: (2 + 1) * 3 = 9.

## Example 2

Input: tokens = ["4", "13", "5", "/", "+"]
Output: 6
Explanation: 4 + (13 / 5) = 4 + 2 = 6.

Constraints: division truncates toward zero, and the expression is always valid.
