# Sliding Window Maximum

**Difficulty:** Hard

Given an array of integers and a window size k, return an array of the maximum values found in each contiguous window of size k as it slides from the beginning to the end of the array.

## Example 1

Input: nums = [1, 2, 1, 0, 4, 2, 3], k = 3
Output: [2, 2, 4, 4, 4]

## Example 2

Input: nums = [1, -1], k = 1
Output: [1, -1]

Constraints: the window size k is always between 1 and the length of the array.

Full problem statement: https://neetcode.io/problems/sliding-window-maximum
