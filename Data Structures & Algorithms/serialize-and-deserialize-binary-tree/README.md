# Serialize and Deserialize Binary Tree

**Difficulty:** Hard

Design an algorithm to convert a binary tree into a string representation and then reconstruct the original tree from that string.

## Example 1

Input: root = [1, 2, 3, null, null, 4, 5]
Output: [1, 2, 3, null, null, 4, 5]
Explanation: Serializing the tree and then deserializing the result should reproduce the original tree structure exactly.

## Example 2

Input: root = []
Output: []

Constraints: node values may be any integer, and the tree may be empty.

Full problem statement: https://neetcode.io/problems/serialize-and-deserialize-binary-tree
