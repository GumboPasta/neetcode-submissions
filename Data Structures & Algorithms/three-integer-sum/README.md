# 3Sum

**Difficulty:** Medium

Given an array of integers, find all unique triplets whose values add up to zero. Each triplet's values must come from different indices, and the result should not contain duplicate triplets.

## Example 1

Input: nums = [-1, 0, 1, 2, -1, -4]
Output: [[-1, -1, 2], [-1, 0, 1]]

## Example 2

Input: nums = [0, 1, 1]
Output: []

Constraints: the array may contain duplicate values, and triplets must be unique.

Full problem statement: https://neetcode.io/problems/three-integer-sum
