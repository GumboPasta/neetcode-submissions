# Median of Two Sorted Arrays

**Difficulty:** Hard

Given two sorted arrays, find the median of the combined set of all elements from both arrays. The algorithm should run in logarithmic time relative to the combined length.

## Example 1

Input: nums1 = [1, 3], nums2 = [2]
Output: 2.0
Explanation: Merging the arrays gives [1, 2, 3], and the median is the middle value, 2.

## Example 2

Input: nums1 = [1, 2], nums2 = [3, 4]
Output: 2.5
Explanation: Merging the arrays gives [1, 2, 3, 4], and the median is the average of the two middle values, (2 + 3) / 2.

Constraints: the combined arrays are never both empty.
