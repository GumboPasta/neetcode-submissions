# Encode and Decode Strings

**Difficulty:** Medium

Design an algorithm to encode a list of strings into a single string, and decode that string back into the original list of strings. The encoding must handle strings containing any characters, including special delimiters.

## Example 1

Input: strs = ["neet", "code", "love", "you"]
Output: ["neet", "code", "love", "you"]
Explanation: Encoding the list into a single string and then decoding it should reproduce the original list exactly.

## Example 2

Input: strs = ["we", "say", ":", "yes"]
Output: ["we", "say", ":", "yes"]

Constraints: strings may contain any characters, including digits, symbols, and spaces.

Full problem statement: https://neetcode.io/problems/string-encode-and-decode
