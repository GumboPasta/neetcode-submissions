# Reorder List

**Difficulty:** Medium

Given the head of a singly linked list, reorder it in place so the nodes alternate between the first half in order and the second half in reverse order, forming the pattern first, last, second, second-to-last, and so on.

## Example 1

Input: head = [2, 4, 6, 8]
Output: [2, 8, 4, 6]

## Example 2

Input: head = [2, 4, 6, 8, 10]
Output: [2, 10, 4, 8, 6]

Constraints: the reordering must be done in place without creating new nodes.

Full problem statement: https://neetcode.io/problems/reorder-linked-list
