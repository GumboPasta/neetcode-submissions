# Merge Two Sorted Lists

**Difficulty:** Easy

Given the heads of two sorted linked lists, merge them into a single sorted list by splicing the existing nodes together, and return the head of the merged list.

## Example 1

Input: list1 = [1, 2, 4], list2 = [1, 3, 4]
Output: [1, 1, 2, 3, 4, 4]

## Example 2

Input: list1 = [], list2 = []
Output: []

Constraints: both lists are already sorted in non-decreasing order.
