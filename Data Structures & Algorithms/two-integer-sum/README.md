# Two Sum

**Difficulty:** Easy

Given an array of integers and a target value, find two numbers in the array whose sum equals the target and return their indices. You can assume exactly one valid pair exists, and the same element cannot be used twice.

## Example 1

Input: nums = [2, 7, 11, 15], target = 9
Output: [0, 1]
Explanation: nums[0] + nums[1] = 2 + 7 = 9.

## Example 2

Input: nums = [3, 2, 4], target = 6
Output: [1, 2]

Constraints: the array has at least two elements, exactly one valid answer exists, and the same element may not be used twice.

Full problem statement: https://neetcode.io/problems/two-integer-sum
