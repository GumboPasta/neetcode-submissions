# Subtree of Another Tree

**Difficulty:** Easy

Given the roots of two binary trees, determine whether one tree contains a subtree that is structurally identical to and has the same node values as the other tree.

## Example 1

Input: root = [1, 2, 3, 4, 5], subRoot = [2, 4, 5]
Output: true
Explanation: The subtree rooted at node 2 matches subRoot exactly.

## Example 2

Input: root = [1, 2, 3, 4, 5, null, null, 6], subRoot = [2, 4, 5]
Output: false

Constraints: both trees contain node values that may repeat.
