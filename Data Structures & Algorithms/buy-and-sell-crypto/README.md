# Best Time to Buy and Sell Stock

Given a list of daily prices for a stock, find the maximum profit achievable from a single buy followed by a later sell. Return 0 if no profit is possible.

## Example

Input: prices = [7, 1, 5, 3, 6, 4]
Output: 5
Explanation: Buy on day 2 (price = 1) and sell on day 5 (price = 6), for a profit of 6 - 1 = 5.

Full problem statement: https://neetcode.io/problems/buy-and-sell-crypto
