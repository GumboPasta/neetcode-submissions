# Longest Repeating Character Replacement

**Difficulty:** Medium

Given a string of uppercase letters and an integer k, find the length of the longest substring that can contain the same letter throughout, after replacing at most k characters in the substring with any other letter.

## Example 1

Input: s = "XYYX", k = 2
Output: 4
Explanation: Both X's can be changed to Y's, or vice versa, to form a substring of all the same letter.

## Example 2

Input: s = "AAABABB", k = 1
Output: 5

Constraints: the string consists of uppercase English letters only.
