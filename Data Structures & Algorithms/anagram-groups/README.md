# Group Anagrams

**Difficulty:** Medium

Given a list of strings, group the strings that are anagrams of each other into their own lists. The order of the groups and the order of strings within a group does not matter.

## Example 1

Input: strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
Output: [["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]

## Example 2

Input: strs = ["x"]
Output: [["x"]]

Constraints: all strings consist of lowercase English letters only.

Full problem statement: https://neetcode.io/problems/anagram-groups
