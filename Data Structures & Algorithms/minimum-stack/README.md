# Min Stack

**Difficulty:** Medium

Design a stack that supports push, pop, top, and retrieving the minimum element, all in constant time.

## Example 1

Input: push(1), push(2), push(0), getMin(), pop(), top()
Output: getMin() returns 0, top() returns 2 after popping
Explanation: After pushing 1, 2, and 0, the minimum is 0. Popping removes 0, leaving 2 on top.

## Example 2

Input: push(-2), push(0), push(-3), getMin(), pop(), top(), getMin()
Output: getMin() returns -3, top() returns 0, getMin() returns -2

Constraints: all operations are called on a non-empty stack when required.

Full problem statement: https://neetcode.io/problems/minimum-stack
