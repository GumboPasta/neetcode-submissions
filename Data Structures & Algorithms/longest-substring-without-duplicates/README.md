# Longest Substring Without Repeating Characters

**Difficulty:** Medium

Given a string, find the length of the longest substring that does not contain any repeated characters.

## Example 1

Input: s = "zxyzxyz"
Output: 3
Explanation: The substring "zxy" has length 3 and contains no duplicates. Since it repeats, no longer duplicate-free substring exists.

## Example 2

Input: s = "xxxx"
Output: 1

Constraints: the string may contain letters, digits, symbols, and spaces.
