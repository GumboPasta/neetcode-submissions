# Binary Tree Level Order Traversal

**Difficulty:** Medium

Given the root of a binary tree, return the values of its nodes grouped level by level, from top to bottom, with each level as its own list.

## Example 1

Input: root = [3, 9, 20, null, null, 15, 7]
Output: [[3], [9, 20], [15, 7]]

## Example 2

Input: root = [1]
Output: [[1]]

Constraints: the tree may be empty, in which case the output is an empty list.
