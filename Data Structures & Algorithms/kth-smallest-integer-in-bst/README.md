# Kth Smallest Element in a BST

**Difficulty:** Medium

Given the root of a binary search tree and an integer k, return the k-th smallest value among all the node values in the tree.

## Example 1

Input: root = [3, 1, 4, null, 2], k = 1
Output: 1

## Example 2

Input: root = [5, 3, 6, 2, 4, null, null, 1], k = 3
Output: 3

Constraints: k is always valid, meaning 1 <= k <= number of nodes in the tree.

Full problem statement: https://neetcode.io/problems/kth-smallest-integer-in-bst
