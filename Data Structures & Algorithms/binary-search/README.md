# Binary Search

**Difficulty:** Easy

Given a sorted array of unique integers and a target value, return the index of the target if it exists in the array, or -1 if it does not. The solution should run in logarithmic time.

## Example 1

Input: nums = [-1, 0, 3, 5, 9, 12], target = 9
Output: 4
Explanation: 9 appears at index 4.

## Example 2

Input: nums = [-1, 0, 3, 5, 9, 12], target = 2
Output: -1
Explanation: 2 does not exist in the array, so -1 is returned.

Constraints: all integers in the array are unique and sorted in ascending order.
