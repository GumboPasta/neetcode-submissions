# Longest Consecutive Sequence

**Difficulty:** Medium

Given an unsorted array of integers, find the length of the longest run of consecutive integers that all appear in the array. The solution should run in linear time.

## Example 1

Input: nums = [100, 4, 200, 1, 3, 2]
Output: 4
Explanation: The longest consecutive run is 1, 2, 3, 4.

## Example 2

Input: nums = [0, 3, 7, 2, 5, 8, 4, 6, 0, 1]
Output: 9

Constraints: the array may contain duplicates and negative numbers.
