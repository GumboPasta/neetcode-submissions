# Valid Palindrome

**Difficulty:** Easy

Given a string, determine whether it reads the same forward and backward after converting all letters to lowercase and removing all non-alphanumeric characters.

## Example 1

Input: s = "Was it a car or a cat I saw?"
Output: true
Explanation: After cleaning, the string becomes "wasitacaroracatisaw", which is a palindrome.

## Example 2

Input: s = "tin man"
Output: false

Constraints: the string may contain letters, digits, spaces, and punctuation.
