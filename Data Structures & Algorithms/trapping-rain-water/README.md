# Trapping Rain Water

**Difficulty:** Hard

Given an array representing the height of bars in an elevation map, where each bar has a width of 1, compute how much water can be trapped between the bars after rain.

## Example 1

Input: height = [0, 2, 0, 3, 1, 0, 1, 3, 2, 1]
Output: 9

## Example 2

Input: height = [4, 2, 0, 3, 2, 5]
Output: 9

Constraints: all heights are non-negative integers.

Full problem statement: https://neetcode.io/problems/trapping-rain-water
