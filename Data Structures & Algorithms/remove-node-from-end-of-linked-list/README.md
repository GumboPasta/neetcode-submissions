# Remove Nth Node From End of List

**Difficulty:** Medium

Given the head of a linked list and an integer n, remove the n-th node counting from the end of the list, and return the head of the modified list, ideally in a single pass.

## Example 1

Input: head = [1, 2, 3, 4, 5], n = 2
Output: [1, 2, 3, 5]

## Example 2

Input: head = [1], n = 1
Output: []

Constraints: n is always valid, meaning it is between 1 and the length of the list.
