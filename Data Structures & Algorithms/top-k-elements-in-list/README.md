# Top K Frequent Elements

**Difficulty:** Medium

Given an array of integers and an integer k, return the k most frequently occurring elements in the array, in any order.

## Example 1

Input: nums = [1, 2, 2, 3, 3, 3], k = 2
Output: [2, 3]

## Example 2

Input: nums = [7, 7], k = 1
Output: [7]

Constraints: the answer is always uniquely determined for the given k.

Full problem statement: https://neetcode.io/problems/top-k-elements-in-list
