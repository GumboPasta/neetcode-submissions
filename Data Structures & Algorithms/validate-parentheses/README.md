# Valid Parentheses

**Difficulty:** Easy

Given a string containing only the characters (, ), {, }, [, and ], determine whether every opening bracket is closed by the same type of bracket in the correct order.

## Example 1

Input: s = "()[]{}"
Output: true

## Example 2

Input: s = "(]"
Output: false

Constraints: the string may be empty and contains only bracket characters.
