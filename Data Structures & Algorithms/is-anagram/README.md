# Valid Anagram

**Difficulty:** Easy

Given two strings, determine whether the second string is an anagram of the first, meaning it uses exactly the same letters with the same frequency, just possibly rearranged.

## Example 1

Input: s = "racecar", t = "carrace"
Output: true

## Example 2

Input: s = "jar", t = "jam"
Output: false

Constraints: both strings consist of lowercase English letters only.
