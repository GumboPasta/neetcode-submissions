# Maximum Depth of Binary Tree

**Difficulty:** Easy

Given the root of a binary tree, return its maximum depth, defined as the number of nodes along the longest path from the root down to the farthest leaf.

## Example 1

Input: root = [3, 9, 20, null, null, 15, 7]
Output: 3
Explanation: The longest path goes from 3 down to either 15 or 7, passing through 20, for a total of 3 nodes.

## Example 2

Input: root = [1, null, 2]
Output: 2

Constraints: the number of nodes ranges from 0 to a large number, and node values fit within the standard integer range.

Full problem statement: https://neetcode.io/problems/depth-of-binary-tree
