# Contains Duplicate

**Difficulty:** Easy

Given an array of integers, determine whether any value appears at least twice in the array. Return true if a duplicate exists, and false if every element is distinct.

## Example 1

Input: nums = [1, 2, 3, 1]
Output: true

## Example 2

Input: nums = [1, 2, 3, 4]
Output: false

Constraints: the array may contain both positive and negative integers.

Full problem statement: https://neetcode.io/problems/duplicate-integer
