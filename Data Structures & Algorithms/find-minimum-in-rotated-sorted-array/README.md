# Find Minimum in Rotated Sorted Array

**Difficulty:** Medium

An array sorted in ascending order has been rotated at some unknown pivot. Given the rotated array with no duplicate values, find and return the minimum element. The algorithm should run in logarithmic time.

## Example 1

Input: nums = [3, 4, 5, 1, 2]
Output: 1

## Example 2

Input: nums = [4, 5, 6, 7, 0, 1, 2]
Output: 0

Constraints: all elements are unique, and the array was originally sorted before being rotated.
