# Product of Array Except Self

**Difficulty:** Medium

Given an array of integers, return a new array where each position holds the product of all the other elements in the original array, without using division and in linear time.

## Example 1

Input: nums = [1, 2, 4, 6]
Output: [48, 24, 12, 8]

## Example 2

Input: nums = [-1, 0, 1, 2, 3]
Output: [0, 0, 0, 0, 0]

Constraints: the product of any prefix or suffix fits within a 32-bit integer.

Full problem statement: https://neetcode.io/problems/products-of-array-discluding-self
