# Two Sum II - Input Array Is Sorted

**Difficulty:** Medium

Given a 1-indexed array of integers already sorted in ascending order, find two numbers that add up to a specific target and return their indices as a list, using only constant extra space.

## Example 1

Input: numbers = [1, 2, 3, 4], target = 3
Output: [1, 2]

## Example 2

Input: numbers = [2, 3, 4], target = 6
Output: [1, 3]

Constraints: exactly one valid pair of indices always exists, and each input element may only be used once.

Full problem statement: https://neetcode.io/problems/two-integer-sum-ii
