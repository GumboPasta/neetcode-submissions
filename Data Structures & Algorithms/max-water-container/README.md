# Container With Most Water

**Difficulty:** Medium

Given an array of heights representing vertical lines drawn at each index, find two lines that together with the x-axis form a container that holds the maximum amount of water.

## Example 1

Input: height = [1, 7, 2, 5, 4, 7, 3, 6]
Output: 36

## Example 2

Input: height = [1, 2, 1]
Output: 2

Constraints: the array contains at least two heights, and each height is non-negative.

Full problem statement: https://neetcode.io/problems/max-water-container
