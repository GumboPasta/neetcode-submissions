# Search a 2D Matrix

**Difficulty:** Medium

Given an m x n matrix where each row is sorted left to right and the first element of each row is greater than the last element of the previous row, determine whether a target value exists in the matrix. The algorithm should run in logarithmic time.

## Example 1

Input: matrix = [[1, 3, 5, 7], [10, 11, 16, 20], [23, 30, 34, 60]], target = 3
Output: true

## Example 2

Input: matrix = [[1, 3, 5, 7], [10, 11, 16, 20], [23, 30, 34, 60]], target = 13
Output: false

Constraints: the matrix has at least one row and one column.

Full problem statement: https://neetcode.io/problems/search-2d-matrix
