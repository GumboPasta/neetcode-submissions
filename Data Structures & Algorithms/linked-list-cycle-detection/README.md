# Linked List Cycle

**Difficulty:** Easy

Given the head of a linked list, determine whether the list contains a cycle, meaning some node can be reached again by continuously following the next pointers.

## Example 1

Input: head = [3, 2, 0, -4], with a cycle connecting the tail back to the node with value 2
Output: true

## Example 2

Input: head = [1, 2], with no cycle
Output: false

Constraints: the list may be empty, and a cycle if present can start at any node.

Full problem statement: https://neetcode.io/problems/linked-list-cycle-detection
