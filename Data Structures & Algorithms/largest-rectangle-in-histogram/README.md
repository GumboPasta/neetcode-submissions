# Largest Rectangle in Histogram

**Difficulty:** Hard

Given an array representing the heights of bars in a histogram, where each bar has a width of 1, find the area of the largest rectangle that can be formed using consecutive bars.

## Example 1

Input: heights = [2, 1, 5, 6, 2, 3]
Output: 10
Explanation: The largest rectangle spans the bars with heights 5 and 6, giving an area of 2 * 5 = 10.

## Example 2

Input: heights = [2, 4]
Output: 4

Constraints: all heights are non-negative integers.
