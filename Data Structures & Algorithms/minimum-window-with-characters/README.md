# Minimum Window Substring

**Difficulty:** Hard

Given two strings s and t, find the smallest substring of s that contains every character of t, including duplicates. Return an empty string if no such substring exists.

## Example 1

Input: s = "OUZODYXAZV", t = "XYZ"
Output: "YXAZ"
Explanation: "YXAZ" is the shortest substring of s that includes the letters X, Y, and Z from t.

## Example 2

Input: s = "xyz", t = "xyz"
Output: "xyz"

Constraints: if no valid window exists, an empty string is returned.
