# Search in Rotated Sorted Array

**Difficulty:** Medium

An array sorted in ascending order with unique values has been rotated at some unknown pivot. Given the rotated array and a target value, return the index of the target if it exists, or -1 otherwise. The algorithm should run in logarithmic time.

## Example 1

Input: nums = [4, 5, 6, 7, 0, 1, 2], target = 0
Output: 4

## Example 2

Input: nums = [4, 5, 6, 7, 0, 1, 2], target = 3
Output: -1

Constraints: all values in the array are unique.

Full problem statement: https://neetcode.io/problems/find-target-in-rotated-sorted-array
