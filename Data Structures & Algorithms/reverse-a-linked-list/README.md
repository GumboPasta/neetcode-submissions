# Reverse Linked List

**Difficulty:** Easy

Given the head of a singly linked list, reverse the list and return the new head.

## Example 1

Input: head = [1, 2, 3, 4, 5]
Output: [5, 4, 3, 2, 1]

## Example 2

Input: head = []
Output: []

Constraints: the list may contain zero or more nodes.
