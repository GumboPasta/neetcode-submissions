# Merge k Sorted Lists

**Difficulty:** Hard

Given an array of k sorted linked lists, merge all of them into a single sorted linked list and return its head.

## Example 1

Input: lists = [[1, 4, 5], [1, 3, 4], [2, 6]]
Output: [1, 1, 2, 3, 4, 4, 5, 6]

## Example 2

Input: lists = []
Output: []

Constraints: the number of lists and their combined length fit within typical array size limits.
