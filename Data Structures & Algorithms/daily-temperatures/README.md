# Daily Temperatures

**Difficulty:** Medium

Given a list of daily temperatures, return a list where each position holds the number of days you must wait after that day to reach a warmer temperature. If no future day is warmer, put 0 for that day.

## Example 1

Input: temperatures = [73, 74, 75, 71, 69, 72, 76, 73]
Output: [1, 1, 4, 2, 1, 1, 0, 0]

## Example 2

Input: temperatures = [30, 40, 50, 60]
Output: [1, 1, 1, 0]

Constraints: temperature values fall within a typical range and the list contains at least one day.

Full problem statement: https://neetcode.io/problems/daily-temperatures
