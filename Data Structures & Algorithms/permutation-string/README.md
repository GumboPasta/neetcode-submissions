# Permutation in String

**Difficulty:** Medium

Given two strings s1 and s2, determine whether s2 contains a contiguous substring that is a permutation of s1.

## Example 1

Input: s1 = "abc", s2 = "lecabee"
Output: true
Explanation: The substring "cab" within s2 is a permutation of s1.

## Example 2

Input: s1 = "abc", s2 = "lecaabee"
Output: false

Constraints: both strings consist of lowercase English letters only.

Full problem statement: https://neetcode.io/problems/permutation-string
