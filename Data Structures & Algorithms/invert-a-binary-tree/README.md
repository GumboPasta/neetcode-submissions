# Invert Binary Tree

**Difficulty:** Easy

Given the root of a binary tree, swap every left and right child recursively throughout the tree, and return the root of the resulting inverted tree.

## Example 1

Input: root = [4, 2, 7, 1, 3, 6, 9]
Output: [4, 7, 2, 9, 6, 3, 1]
Explanation: Each node's left and right children are swapped at every level.

## Example 2

Input: root = [2, 1, 3]
Output: [2, 3, 1]

Constraints: the tree may be empty, in which case the output is also empty.

Full problem statement: https://neetcode.io/problems/invert-a-binary-tree
