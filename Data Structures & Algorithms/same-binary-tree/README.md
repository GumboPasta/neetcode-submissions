# Same Tree

**Difficulty:** Easy

Given the roots of two binary trees, determine whether they are structurally identical and have the same node values at every position.

## Example 1

Input: p = [1, 2, 3], q = [1, 2, 3]
Output: true

## Example 2

Input: p = [1, 2], q = [1, null, 2]
Output: false

Constraints: both trees may be empty.

Full problem statement: https://neetcode.io/problems/same-binary-tree
