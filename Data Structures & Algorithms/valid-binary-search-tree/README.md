# Validate Binary Search Tree

**Difficulty:** Medium

Given the root of a binary tree, determine whether it is a valid binary search tree, meaning every node's value is greater than all values in its left subtree and less than all values in its right subtree.

## Example 1

Input: root = [2, 1, 3]
Output: true

## Example 2

Input: root = [1, 2, 3]
Output: false
Explanation: The root's value of 1 is less than the value 2 in its right subtree, violating the BST property.

Constraints: node values are unique integers.
